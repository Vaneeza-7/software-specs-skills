# Software Specs

Skills that help Claude spec software and projects.

| Skill | What it does |
|---|---|
| `diagrams` | Draws architecture, data flow (DFD) and process flow diagrams in a consistent, spec-ready style. |

Ask for a diagram while speccing, for example "Draw the architecture diagram for this system", and Claude picks the right type and applies its conventions.

Source, install steps for Claude Code and Claude chat, and license: https://github.com/Vaneeza-7/software-specs-skills
