# Software Specs

Skills that help Claude spec software and projects.

| Skill | What it does |
|---|---|
| `diagrams` | Draws architecture, data flow (DFD) and process flow diagrams in a consistent, spec-ready style. |
| `technical-proposal` | Writes technical proposals and implementation plans with modules, tech stack, architecture, and a milestone timeline with acceptance criteria. |

Ask while speccing, for example "Draw the architecture diagram for this system" or "Write a client technical proposal for this build", and Claude picks the matching skill and applies its conventions.

Source, install steps for Claude Code and Claude chat, and license: https://github.com/Vaneeza-7/software-specs-skills
